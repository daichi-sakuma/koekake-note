声かけ活動ノート（GitHub Pages 用）

このフォルダ内のファイルを、すべてGitHubのリポジトリの一番上（ルート）にアップロードします。
ZIPファイルをそのままアップロードするのではなく、展開して中のファイルをアップロードしてください。

1. index.html : アプリ本体
2. manifest.webmanifest : ホーム画面表示設定
3. icon-192.png / icon-512.png / apple-touch-icon.png : アイコン
4. sw.js : 一度読み込んだ後のオフライン利用を助けるファイル

無料のGitHub Pages公開は、リポジトリをPublicにして使用します。
振り返りの入力内容はブラウザ内の保存領域に保存され、GitHubには送信されません。
ブラウザデータの削除や別端末への移行で消える場合があるため、「データを書き出す」でバックアップしてください。
Webサイトを更新したあとにはブラウザの再読み込みが必要になる場合があります。
