声かけ活動ノート v5 — GitHub Pages用

【公開方法】
1. ZIPを展開し、中にある7ファイルをすべて選択します（ZIPをそのままアップロードしない）。
2. GitHubの既存リポジトリ koekake-note を開き、Add file → Upload files を選択。
3. 7ファイルをアップロードし、Commit changes を押してください。上書きでOKです。
4. Settings → Pages → Deploy from a branch / main / /(root) を設定（設定済みなら不要）。
5. https://＜GitHubユーザー名＞.github.io/koekake-note/ にアクセスします。
6. iPhoneはSafariの共有 → ホーム画面に追加。AndroidはChromeメニュー → ホーム画面に追加 / アプリをインストール。

【重要】
・日付＋場所ごとに自動保存。日付が変わると新しい日のカウンターは0から開始（過去データは残る）。
・結果区分（ガンシカ、目線だけ、一言反応、オープン）は各声かけにつき原則1つ。連れ出しと連絡先交換は別集計。
・活動前に11項目の実践チェックを確認できます。チェック状態は日付が変わると自動でリセットされます。
・活動後の振り返りでも同じ11項目を記録し、集計画面で達成率の低い項目から確認できます。
・11項目の名称・説明・グループ名は設定タブから変更できます。過去記録との対応を保つため、項目数は変更できません。
・「分岐フロー」では12場面、61段階、172個の選択肢から、相手の反応に応じた次のトークを確認できます。
・場面をまたいで「帰り」「仕事」「買い物」「待ち合わせ」「連れ出し」「連絡先交換」「終了」へ移動できます。
・明確な拒否や不快そうな反応がある場合は、それ以上追わずに終了してください。
・データは端末のブラウザのlocalStorageに保存。ブラウザデータの削除で失われる可能性があります。
・設定タブから「バックアップ保存」を定期的に行ってください。復元はv5形式のJSONに対応します。
・v4の旧データは同じブラウザに保存されている場合、初回のみ可能な範囲で引き継ぎを試みます。元データは削除しません。
・GitHub公開リポジトリに個人の活動データやバックアップJSONをアップロードしないでください。
